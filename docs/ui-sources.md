## 1. Executive Summary & Design Purpose

In an academic assistant system for university students, factuality, transparency, and trust are paramount. When students query office locations, opening hours, or graduation regulations, they must be able to verify where the information originated.

This document defines the **User Interface (UI) and User Experience (UX) specification for displaying source citations directly beneath every assistant response**.

### Key Design Goals
1. **Unambiguous Source Attribution:** Never display an answer without attributing its data origin (e.g., CSV database row, handbook section, or administrative announcement).
2. **Support Dual Paradigms:**
   - **Deterministic Mode:** Clear attribution for rule-based tabular data (`data/offices.csv`).
   - **RAG / AI Synthesis Mode:** Transparent citation of document chunks, page numbers, and semantic confidence scores.
3. **Clean Visual Hierarchy:** The answer text remains prominent and easily readable, while citation metadata is elegantly docked beneath it without visual clutter.
4. **Interactive Verification:** Students can expand a citation drawer to inspect the exact verbatim source text or download/open the referenced document.

---

## 2. Citation Data Schema

Every response generated by the assistant pipeline attaches an optional list of citation objects with the following schema:

```json
{
  "source_type": "structured_csv",
  "file_path": "data/offices.csv",
  "title": "Phòng Đào tạo (Training Office)",
  "reference_location": "Row #2 | Room I.101",
  "confidence_score": 1.0,
  "last_updated": "2026-10-18",
  "snippet": "Training Office,I.101,Mon-Fri 07:30-16:30"
}
```

*Allowed enum values for `source_type`:*
- `"structured_csv"`: Deterministic tabular data lookup (e.g., `data/offices.csv`).
- `"rag_document"`: Unstructured document chunk from vector search / LLM synthesis (e.g., university handbooks).
- `"web_announcement"`: Official web announcement or circular.
- `"unknown"`: Fallback when source metadata is unverified or unspecified.


---

## 3. UI Component Anatomy & Tokens

The citation block rendered below each assistant message consists of 4 atomic elements:

1. **Source Header Badge (`DataOriginTag`):**
   - Icon: `📌` (for deterministic local records) or `📚` (for official documents/handbooks).
   - Color: Accent Green (`hsl(158, 64%, 52%)`) denoting verified institutional data.
   - Label: Relative path and section/row reference.
2. **Confidence / Verification Chip (`VerificationBadge`):**
   - Deterministic: `[ Verified Match 100% ]`
   - RAG / Semantic: `[ Similarity Score: 0.92 ]`
3. **Expandable Source Evidence Drawer (`EvidenceSnippet`):**
   - Collapsible panel (`st.expander`) displaying the exact excerpt from the file to guarantee auditability.
4. **Action Toolbar:**
   - One-click copy of the citation reference for academic use.
   - Direct link or file reference button.

## 5. Implementation Guide for Streamlit (`ui/app.py`)

Below is the reference Python implementation for rendering the citation cards in the Streamlit web interface:

```python
import html
import streamlit as st


def render_citation(citation: dict) -> None:
    """Render a clean, transparent source citation block under an assistant message."""
    if not citation:
        return

    source_type = citation.get("source_type", "unknown")
    if source_type == "structured_csv":
        icon = "📌"
        badge_label = "CSDL Xác thực (100%)"
    elif source_type == "rag_document":
        icon = "📚"
        badge_label = f"RAG Match ({citation.get('confidence_score', 0):.1%})"
    else:
        icon = "ℹ️"
        badge_label = "Chưa xác minh (Unverified)"

    # Sanitize dynamic inputs with html.escape to prevent XSS / HTML injection in unsafe_allow_html
    safe_file_path = html.escape(str(citation.get("file_path", "")))
    safe_icon = html.escape(str(icon))
    safe_badge_label = html.escape(str(badge_label))
    safe_ref_location = html.escape(str(citation.get("reference_location", "")))

    with st.container():
        st.markdown(
            f"""
            <div style="border-left: 3px solid #22c55e; padding-left: 12px; margin-top: 10px; background-color: rgba(34, 197, 94, 0.05); border-radius: 4px; padding-top: 6px; padding-bottom: 6px;">
                <span style="font-size: 0.85rem; font-weight: 600; color: #16a34a;">{safe_icon} NGUỒN: {safe_file_path}</span>
                <span style="float: right; font-size: 0.75rem; background-color: #dcfce7; color: #15803d; padding: 2px 8px; border-radius: 12px;">{safe_badge_label}</span>
                <div style="font-size: 0.8rem; color: #4b5563; margin-top: 4px;">{safe_ref_location}</div>
            </div>
            """,
            unsafe_allow_html=True,
        )

        snippet = citation.get("snippet")
        if snippet:
            with st.expander("🔍 Xem trích đoạn nguồn đối chiếu"):
                st.code(snippet, language="text")
```
